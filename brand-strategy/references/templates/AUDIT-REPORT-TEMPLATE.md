# {{Brand Name}} — Brand Audit Report
### {{Date}}

> 📋 **Purpose:** Diagnose an existing brand's problems before prescribing fixes. This is the "Diagnose Before Prescribing" workflow: run all four diagnostics, synthesize the root cause, and only then prescribe — ranked, law-grounded, and subtractive.
>
> 📋 **Standalone template** — not part of the numbered 1–5 launch sequence. Use it when a brand, product, or campaign is struggling and the deliverable is a diagnosis, not a new brand.
>
> 📋 **Method rules:**
> - Diagnosis before prescription. Do not write a single fix until all four diagnostics are complete and the root cause is stated.
> - Every violation gets evidence — a behavior, message, or artifact you can point to. "The positioning feels weak" is an impression; "the homepage claims three different categories" is evidence.
> - Prescriptions subtract. The answer is almost always to do fewer things better. A prescription that expands scope, features, or audience needs explicit justification.
> - Never prescribe better advertising to fix a positioning problem. Advertising amplifies — it does not correct.
>
> 📋 Delete all `📋` blocks from the finished document.
